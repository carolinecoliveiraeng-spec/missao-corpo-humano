# Missão Corpo Humano — versão avançada

Aplicação educacional estática para Ensino Médio, construída em HTML, CSS e JavaScript.

## Conteúdo
- 11 módulos de Anatomia e Fisiologia: contextualização, anatomia, fisiologia, regulação e integração.
- 22 questões formativas com feedback explicativo.
- 3 situações-problema integradoras.
- Escape Room Operação Homeostase com 5 salas, evidências fictícias, hipóteses, pistas, cronômetro e código final.
- Microsoft Forms incorporado na seção de registro.

## Publicação
Extraia o ZIP e envie os arquivos `index.html`, `style.css`, `app.js` e `README.md` para a raiz do repositório GitHub. Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/(root)` e salve.

## Privacidade
O site não possui backend nem armazena dados pessoais. O formulário é servido diretamente pelo Microsoft Forms. Dados e valores apresentados nos casos do Escape Room são fictícios e exclusivamente didáticos.
